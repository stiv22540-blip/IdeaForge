# IdeaForge ✦

**Придумай. Оцени. Сделай.** Выбираешь, что делаем, — 💻 приложение, 🎮 игру, 🌐 сайт, 🧩 мод, 🤖 Telegram-бота или 🎬 ролик для TikTok — пишешь тему, например «для дома» или «факты про космос», и ИИ-агент:

1. **придумывает** 5/10/15 идей на эту тему;
2. **анализирует** каждую: польза, реализуемость, новизна, вау-эффект — и выбирает лучшую;
3. **сам делает** лучшую идею в отдельной папке и проверяет результат:
   - приложение, игра, сайт — рабочий код (обычно один `index.html`);
   - мод — проект на стандартных инструментах игры (Fabric/Forge, tModLoader, SMAPI…), по возможности сразу собранный в `dist/`;
   - бот — код на Python/Node, токен кладётся в `.env`;
   - ролик — готовый вертикальный `video.mp4` 1080×1920, собранный на [Remotion](https://www.remotion.dev) (нужен только Node.js), плюс `scenario.md` со сценарием, подписью и хэштегами. Remotion бесплатен для частных лиц и компаний до 3 человек, большим компаниям нужна лицензия.

Остальные идеи не пропадают — они лежат в **«Банке идей»**, любую можно сделать потом одной кнопкой.
Готовые приложения — во вкладке **«Сделано»**: запустить, открыть папку или VS Code, попросить агента доработать.

## Какие агенты поддерживаются

| Агент | Установка |
|---|---|
| [Claude Code](https://claude.com/claude-code) | `npm i -g @anthropic-ai/claude-code`, затем `claude` → войти в аккаунт |
| [Codex](https://github.com/openai/codex) | `npm i -g @openai/codex`, затем `codex` → войти |
| [OpenCode](https://opencode.ai) | `npm i -g opencode-ai` |

Агент работает через твою подписку или ключ — IdeaForge просто запускает его CLI. Команды и аргументы можно поменять во вкладке «Настройки».

## Запуск из исходников

Нужен [Node.js 18+](https://nodejs.org). Зависимостей нет.

- **Windows:** двойной клик по `start.bat`
- **macOS:** двойной клик по `start.command`
- **Любая система:** `node server.js`

Откроется браузер на `http://localhost:4777`. Порт меняется переменной `PORT`.

## ⚠️ Важно про безопасность

На шаге «Делаю» агент запускается **с полными правами** (у Claude Code это `--dangerously-skip-permissions`, у Codex — `--full-auto`): он сам создаёт файлы и запускает команды без подтверждений. Задание просит работать только в папке проекта, но это просьба, а не жёсткое ограничение. Если хочешь осторожнее — во вкладке «Настройки» замени аргументы разработки, например на `-p --permission-mode acceptEdits --output-format stream-json --verbose` (тогда агент сможет править файлы, но не запускать команды).

Сервер слушает только `127.0.0.1` и принимает запросы только со своей страницы.

## Где что лежит

- `data.json` — все идеи и настройки
- `projects/` — готовые приложения (папку можно поменять в настройках), в каждом — `ideaforge.log` с логом агента
